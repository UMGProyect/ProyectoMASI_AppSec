# Proyecto final — Centro Médico Premier

Rama documental independiente. Las evidencias se organizan por fase bajo `Evidencias/`.

El repositorio es público: no publicar credenciales, tokens, cookies, datos personales o clínicos, respaldos de bases de datos ni detalles sensibles de explotación. Conservar originales localmente. Revisar y anonimizar antes de subir; rotar las credenciales de prueba compartidas.

Las carpetas originales pueden conservar sus nombres. No fusionar esta rama con main sin autorización.

- `Evidencias/Fase-01-Riesgos/`: Inventario, amenazas y matrices iniciales.
- `Evidencias/Fase-02-Arquitectura/`: Capturas de configuración Cloud, IAM, TLS, respaldos y perímetro.
- `Evidencias/Fase-03-DevSecOps/`: Colocar aquí la carpeta Integraciones de Seguridad completa, previa revisión.
- `Evidencias/Fase-04-Ciberdefensa/Caja-Negra/`: Capturas y reportes revisados de OWASP ZAP.
- `Evidencias/Fase-04-Ciberdefensa/Caja-Gris/`: Colocar aquí la carpeta Pentesting caja gris completa, previa revisión.
- `Evidencias/Fase-04-Ciberdefensa/Caja-Blanca/`: Evidencias de revisión de código y configuraciones, sin detalles sensibles.
- `Evidencias/Fase-05-CloudSec/`: Colocar aquí la carpeta Evaluación CloudSec completa, previa revisión.
- `Evidencias/Fase-06-Mitigacion/`: Propuestas y matrices de riesgo. Distinguir controles proyectados de implementados.
